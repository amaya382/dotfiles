# Purpose playbooks

目的は流れ・何が属するか・何が属さないか・いつ止めるかを決める。後から貼るラベルではない。書きたいことが目的に収まらないなら、目的の選択が間違っている。

**文書の種別 (ADR、仕様書、README) ではなく方向性で選ぶ。** 同じ ADR でも、判断を正当化する本体は 主張 だが、そこに至る前提の説明が長ければその節は 説明 である。

**選び方:** 文書全体で一つ選ぶのが既定。ただし節ごとに方向性が明確に分かれる文書 (README のように、概念の 説明 とセットアップの 手順 が同居するもの) では、節に型を割り当ててよい。その場合は Frame の骨組みで節ごとに型を記録し、各節はその型の playbook に従う。

型が混在してよいのは、節の境界と型の境界が一致するときだけ。一つの節の中で説明と手順が絡み合うなら、それは節の切り方が間違っている。分けられないなら、それは二つの文書である。

**閾値:** 説明の節の末尾にコマンドが1つ付く程度なら、節を割らずに説明のままでよい。読者が順に実行する操作が2つ以上並んだら、そこから先は手順の節として切り出す。

**各型の記述:**
- **中心の力学** — この文書が動く唯一の力。他はすべてここから従う
- **書くべきこと** — 読者がそれなしには目的を達成できないもの。該当がなければ書かない (項目を埋めるために内容を作らない)
- **書かないこと** — この目的が特に引き寄せる埋草
- **停止条件** — 文書が完成したことを示す信号

---

## 説明 — 読者が概念を理解する

**中心の力学.** 読者の既存の理解から、まだ持っていない理解へ渡す。渡す順序がすべてで、順序さえ正しければ説明は短くて済む。長い説明はたいてい順序を間違えている。

**書くべきこと.**
- 読者が既に持っている足場。そこから始める一点
- 理解を成立させる仕組み。「何であるか」ではなく「なぜそうなるか」
- 読者が自然に持つ誤解と、それが誤りである理由
- 理解できたかを読者自身が確かめられる具体例をひとつ

**書かないこと.**
- 概念の歴史や出自。理解に効かないなら書かない
- 「なぜこれが重要か」の段落。重要さは説明が通じた時点で読者が自分で気づく
- 用語の網羅的な定義リスト。理解に使わない用語は定義しない
- 類似概念との比較。読者が混同する具体的な理由がある場合を除く

**停止条件.** 読者が仕組みを自分の言葉で言い直せる。網羅ではない。

**この型の埋草.** 「まだ説明していない気がする」という不安から足された段落。それは読者ではなく書き手のためのものである。概要を先に置き、詳細を後に置く順序を守れば、この不安はたいてい消える。

---

## 手順 — 読者が再現できる

**中心の力学.** 読者の手元で同じ結果が出ること。読者は理解しに来たのではなく、実行しに来ている。

**書くべきこと.**
- 前提条件。何が揃っていれば始められるか
- 順序どおりの操作。実行するものはコードブロックに置く
- 各段階の成功の確認方法。次に進んでよいと読者が判断できる材料
- 失敗時の戻し方

**書かないこと.**
- 手順の設計思想。なぜこの方法なのかは別の文書 (説明) に属する
- 「〜することで効率化されます」のような効能書き
- 実行しない選択肢の説明。読者が選べる分岐があるなら手順として書き、なければ触れない

**停止条件.** 読者が上から順に実行して同じ結果に到達する。

**この型の埋草.** 説明の混入。なぜその手順なのかを書き始めた時点で、文書は 説明 に移っている。理由を書きたくなったら、それが手順の実行に必要か問う。必要なら一節に収め、そうでなければ落とす。

---

## 主張 — 読者が選択を受け入れる

**中心の力学.** 判断の理由を読者に検証させる。読者が同意しなくても、なぜそう判断したかを再構成できるなら成功。説得の力は主張の強さではなく、退けた選択肢の扱いの誠実さから来る。

**書くべきこと.**
- 主張そのもの、一文で。冒頭に置く
- その判断を成立させた決定的な理由。複数あるなら、実際に効いた順に
- 真剣に検討して退けた選択肢と、退けた理由
- 判断が変わる条件。何が起きたらこの結論は覆るか

**書かないこと.**
- 検討しなかった選択肢を、検討したふりで並べること。3案あるうち1案しか本気で見ていないなら、そう書く
- 「一長一短」「ケースバイケース」で判断を回避する結び
- 理由が足りないときの形容詞の重ね塗り
- 実際には来ていない反論への予防線

**停止条件.** 反対の立場の読者が、同意しないまま「なぜそう判断したか」を再構成できる。

**この型の埋草.** 選択肢の対称的な扱いとして現れる。本命1案と当て馬2案を同じ分量で書くと、主張そのものが形によって打ち消される。本命に仕組みと実例を与え、退けた案は一行か表の一行に畳む。

---

## 記録 — 読者が経緯を再構成できる

**中心の力学.** 後から来た人が「なぜこうなったか」を復元できること。読者は未来の他人であり、自分自身も含む。

**書くべきこと.**
- 起きたこと。時系列と事実
- 判断と、その時点で持っていた情報。後から分かったことと区別する
- 判断の結果

**書かないこと.**
- 後知恵の評価。当時知り得なかったことを基準に当時の判断を採点しない
- 教訓の一般化。「この件から学べることは」で始まる段落
- 「今後の改善点」の定型リスト。実際に決まった変更があるなら事実として書き、なければ書かない

**停止条件.** 当時いなかった人が経緯を追える。

**この型の埋草.** 反省文の型。「今後は〜に留意する」は記録ではない。記録に評価を混ぜると、事実と解釈の境界が消えて再構成できなくなる。

**構成上の注意.** この型では時系列が構成を決める。概要を先に置く原則は、冒頭に結果の要約を一段落置く形で満たし、本体は時系列のままにする。

---

## 解説 — 読者が読み続け、視点を得る

**中心の力学.** 読者が自分から次の段落を読む理由を切らさない。5型で唯一、リズムが一級の関心事になる。

**書くべきこと.**
- 読者が引っかかる具体的な問い
- その問いが解けていく過程。結論だけでなく
- 途中の逡巡や見落とし。書き手が実際に judgment を保留した箇所
- 視点の転換点

**書かないこと.**
- 網羅性のための節。「一応触れておくと」で始まる部分
- 読者が既に知っていることの確認
- 装置の実況。「ここで一度立ち止まる」「先に結論を置く」

**停止条件.** 読者が読む前と違うものの見方を持って終わる。

**この型の埋草.** 「厚みを出すため」の段落。面白くする目的で足された段落は、必ず面白くない。

**リズム.** この型に限り、認知の型を意識して配置する。観察 (何があるか) → 逡巡 (だが引っかかる) → 断定 (実はこうだ) → 再観察 (最初の事実が違って見える)。同じ型の段落を3つ続けない。特に断定が3つ続くと、どれだけ内容が良くても平板に読める。各節の終わりで、次の節が答える問いを一つ開いたままにする。
