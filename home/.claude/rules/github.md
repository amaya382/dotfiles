# rules for GitHub

- 指示がない限り Pull Request (PR) は Draft で作成すること
- PR の作成には create-pr skill を使うこと
- PR を作成するとき、assignee に Ryuichi Ito (amaya382) を設定すること
- PR が完成したら PR へのリンクを報告すること
- PR へ追加の push をするときは必ず create-pr skill で PR description も更新すること
- push 先のリポジトリに PR template がある場合は、それを使うこと
- PR を stack するときは `gh stack` を利用すること
