# rules for GitHub

- 指示がない限り Pull Request (PR) は Draft で作成すること
- PR 作成は create-pr skill を使うこと
- PR を作成するとき、assignee は Ryuichi Ito (amaya382) を設定すること
- PR が完成したら PR へのリンクを報告すること
- PR へ push するときは必ず PR description も更新すること
- push 対象 repository に PR template がある場合は利用すること
- PR を stack させるときは `gh stack` を利用すること
  - stacked PRs が有効化されていないリポジトリはその限りではない
