# rules for wording

技術文書としての構成・論証の規範は `technical-document.md` と `~/.claude/references/technical-document-ja.md` を参照すること

## 無理な日本語訳をしない

- 専門用語を無理に日本語に訳したり漢語にしたりしない
  - カタカナ表現が十分流通しているならカタカナ表記を使う（例: コンパイラーの版 → コンパイラーのバージョン）
  - カタカナ表現もまだ定着していない場合は、日本語文中でも英単語のまま書いてよい
- 無生物主語を人間のように例えた表現は日本語では多用しない
  - 例: 「このデータが物語る」「システムが教えてくれる」のような擬人化表現は避け、行為者や仕組みを主語にする

## 表記

- 無理に漢字を使わず日本語的に一般的な表記を使う（例: 「Option C を採る」→「Option C をとる」）
