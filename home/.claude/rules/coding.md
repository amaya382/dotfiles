# rules for coding

- 基本的にコード内コメントは英語としつつ、明らかに日本語で進行しているリポジトリに限り日本語で書くこと
- コードコメントは過去の実装との差分に基づくのではなく、必ず今の実装に対して書くこと
- コードコメントでの justification は最大 1 文に収めること
- Easy ではなく Simple な設計・実装を優先的に採用すること
