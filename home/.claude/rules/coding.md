# rules for coding

- Easy ではなく Simple な設計・実装を優先的に採用すること

## コード内コメント

- 基本的に英語としつつ、明らかに日本語で進行しているリポジトリに限り日本語で書くこと
- 過去の実装との差分に基づくのではなく、必ず今の実装に対して書くこと
- 現在の作業コンテキストを書くのではなく、コードベースを読むときに必要となる情報を書くこと
- justification は最大 1 文に収めること
